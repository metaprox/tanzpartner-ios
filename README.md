# Tanzpartner Ostfriesland iOS

Native SwiftUI-App. Ziel: eine unabhängige, regionale Tanzpartner-Börse für Ostfriesland im öffentlichen App Store – Gesuche ohne Konto, Kontakt per E-Mail-Weiterleitung, Moderation vor Veröffentlichung. Hobbyprojekt ohne finanzielle Interessen.

Derzeit vorhanden: lokaler Prototyp mit fiktiven Profilen, Suche/Filter, Moderation und Kontakt-Simulation sowie ein geschützter Server-Test (PHP/MariaDB). Ziel, Entscheidungen und Stand: [ROADMAP.md](ROADMAP.md).
